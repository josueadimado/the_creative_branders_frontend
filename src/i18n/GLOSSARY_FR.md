# French glossary (v1)

Target: business French for West Africa + France visitors (`fr`, not `fr-CA`).

## Register
- Always **vouvoiement** (`vous`).
- Warm and plain, not stiff corporate French.

## Preferred terms
| EN | FR |
|---|---|
| Start a project | Démarrer un projet |
| Work / Our work | Réalisations / Nos réalisations |
| Case study | Étude de cas |
| Free systems audit | Audit système gratuit |
| Brand and websites | Marque et sites web |
| Web applications | Applications web |
| Mobile apps | Applications mobiles |
| Automation and reporting | Automatisation et rapports |
| Client portal | Portail client |
| Account manager | Chargé de compte |
| Email | E-mail |
| Optional | Facultatif |
| Select | Sélectionner |
| Coming soon | Bientôt |
| Insights (menu) | Articles |
| Ownership (value) | Implication |
| Responsibility (value) | Responsabilité |
| Care (value) | Soin |
| Clarity (value) | Clarté |

## Keep in English when product/tech names
WhatsApp, CRM, SmartCRM, App Store, Paystack, Square, Stripe, Mobile money, Cookies, brief (agency term).
